# 🍫 Chocolate Manufacturing Data Warehouse

## 📌 Project Overview
This project demonstrates the design and implementation of an Enterprise Data Warehouse for a chocolate manufacturing company.

The solution integrates data from multiple business departments into a centralized SQL Server Data Warehouse using a Star Schema design to support business intelligence and analytics.

---

## 🎯 Business Objectives

- Centralize manufacturing data.
- Improve reporting performance.
- Support business decision making.
- Prepare data for Power BI dashboards.
- Build a foundation for Predictive Maintenance and Machine Learning.

1. Extract CSV files

3. Data Cleaning
4. Validation
5. Load Master Tables
6. Populate Data Warehouse
7. Create Relationships
8. Build Star Schema
